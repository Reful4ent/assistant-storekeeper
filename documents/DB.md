# База данных

### Склад компании (CompanyWarehouse)

Поля:

- id - идентификатор склада
- name - название склада

### Номенклатура (Nomenclature)

Поля:

- id - идентификатор номенклатуры
- name - название номенклатуры

### Товары на складе (CompanyWarehouseNomenclature)

Поля:

- id - идентификатор товара на складе
- companyWarehouseId - идентификатор склада
- nomenclatureID - идентификатор номенклатуры
- quantity - количество

### Перемещение (Movement)

Поля:

- id - идентификатор перемещения
- companyWarehouseFromId - идентификатор склада откуда пришел перемещаемый товар (null - приход на склад извне)
- companyWarehouseToId - идентификатор склада куда пришел перемещаемый товар (null - расход не на наши склады)
- date - дата
- status - значение из енам coming - приход, consuption - расход, moving - перемещение

### ТМЦ(MovementNomenclature)

Поля:

- id - идентификатор товара на складе
- goodBeingMovedId - идентификатор перемещения
- movementId - идентификатор номенклатуры
- quantity - количество
